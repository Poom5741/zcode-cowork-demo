# เฉลย Use case 3 — ค้นนโยบายค่าคอมมิชชั่นในโฟลเดอร์

คำถามของเดโม: **"บริษัทจ่ายค่าคอมมิชชั่นพนักงานขายยังไง อัตราปัจจุบันเท่าไหร่"**

คำตอบมี 3 ไฟล์ (จาก 104 ไฟล์):

1. `เอกสารสำคัญ_นโยบาย_คอมมิชชั่น_01.docx` — นโยบายปี 2567: หน้าร้าน 1.0% (เกิน 1M ได้ 2.5% ส่วนเกิน) · ออนไลน์ 3.0%
2. `เอกสารสำคัญ_ประชุม_คอมมิชชั่น_02.docx` — มติประชุมปี 2568: **ปรับออนไลน์เป็น 3.5% + คอมพิเศษเป้าไตรมาส +0.5% (มีผล 1 ม.ค. 2568 แต่ยังรอประกาศ)**
3. `เอกสารสำคัญ_HR_คอมมิชชั่น_03.docx` — ตารางจ่ายจริง ไตรมาส 3/2568

⚠️ กับดัก 2 จุดที่ AI ต้องหลุดไม่ได้:
- ไฟล์สัญญาเอเจนซี่ พูดถึง "คอมมิชชั่นแอฟฟิลิเอต 8%" — **ไม่ใช่**ค่าคอมพนักงานขาย (ห้ามนำมาตอบ)
- คำตอบที่ถูกต้องต้องสังเกตว่านโยบาย 2567 **ล้าสมัยแล้ว** — มติประชุม 2568 ปรับแล้วแต่ยังรอประกาศ → AI ที่ดีต้องชี้ว่า "เอกสารขัดแย้งกัน และไหนใหม่กว่า"

สิ่งที่เดโมดีควรได้: ชี้ 3 ไฟล์ · สังเคราะห์อัตราล่าสุด · เตือนว่ามติประชุมยังรอประกาศ = ต้องยืนยันกับ HR ก่อนบอกพนักงาน
