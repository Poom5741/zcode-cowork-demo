# Use case 3 — หานโยบายค่าคอมมิชชั่นในโฟลเดอร์ 104 ไฟล์

## สถานการณ์

เพื่อนพนักงานใหม่ถามว่า "ค่าคอมมิชชั่นพนักงานขายคิดยังไง"
คุณรู้ว่า*มี*เอกสารอยู่ที่ไหนสักแห่ง — แต่โฟลเดอร์บริษัทมี 100+ ไฟล์ ค้นด้วยชื่อไฟล์ไม่เจอ
ปัญหาซ้อน: เอกสารเก่ากับมติประชุมใหม่**ขัดแย้งกัน** และมีไฟล์ที่พูดถึงคำว่า "คอมมิชชั่น" แต่*ไม่ใช่*เรื่องเดียวกัน

## ไฟล์

- `company-files/` — **104 ไฟล์** (ประชุม/นโยบาย/HR/จัดซื้อ/ลูกค้า ปี 2566–2568) — เข็มซ่อน 3 อัน + กับดัก 1 อัน
- `answer/answer-key.md` — เฉลย

## Prompt ตัวอย่าง (วางให้ ZCode)

> ในโฟลเดอร์ company-files คือเอกสารบริษัท 104 ไฟล์
> หน่อยถามว่า: บริษัทจ่ายค่าคอมมิชชั่นพนักงานขายยังไง อัตรา**ปัจจุบัน**เท่าไหร่
> ข้อกำหนด: อ้างอิงจากไฟล์จริง (ระบุชื่อไฟล์) · ถ้าเอกสารขัดแย้งกันให้ชี้และบอกว่าอันไหนใช้ได้ · ห้ามหยิบเรื่องที่ไม่เกี่ยวมาปน

## จุดที่เดโมต้องดู (จุดขายจริงของ use case นี้)

1. AI ต้องเจอ 3 ไฟล์เข็มจาก 104 ไฟล์ (นโยบาย 2567 · มติประชุม 2568 · ตารางจ่ายจริง)
2. AI ต้อง**ไม่**หลอมรวมไฟล์สัญญาเอเจนซี่ (คอมมิชชั่นแอฟฟิลิเอต 8% — ไม่ใช่ค่าคอมพนักงาน)
3. AI ต้องชี้ว่า **นโยบาย 2567 ล้าสมัยแล้ว** — มติประชุม 2568 ปรับอัตราออนไลน์เป็น 3.5% + คอมพิเศษ +0.5% (แต่ยังรอประกาศเป็นทางการ)
4. ประโยคปิดที่ดีที่สุดจาก AI: "ตอบตามมติประชุม 2568 ได้ แต่แนะนำให้ยืนยันกับ HR ก่อน เพราะยังรอประกาศ"

→ จุดที่ 4 คือบทสรุปของทั้งคอร์ส: **AI ที่ใช้ได้จริงไม่ใช่แค่ค้นเก่ง แต่รู้ว่าเอกสารไหนขัดแย้ง ไหนใหม่กว่า และกล้าบอกว่า "อันนี้ยังไม่ official"**
