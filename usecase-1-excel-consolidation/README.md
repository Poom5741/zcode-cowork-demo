# Use case 1 — รวมรายงานยอดขาย 30 สาขา

## สถานการณ์

คุณคือพนักงานสำนักงานใหญ่ ฝ่ายขาย — ทุกเดือนสาขา 30 แห่งส่ง Excel รายงานยอดขายกลับมา
เดิมทีคุณต้อง: เปิดทีละไฟล์ → ก๊อปวาง → เจอไฟล์ว่างต้องไล่โทร → เจอเลขผิดต้องเดา
เดี๋ยวนี้: โยนทั้งโฟลเดอร์ให้ AI ทำ พร้อมรายงานจุดผิดปกติ

## ไฟล์

- `template-ที่ส่งให้สาขา.xlsx` — แบบฟอร์มต้นฉบับที่บริษัทส่งให้สาขากรอก
- `branches/` — **30 ไฟล์** ที่สาขาส่งกลับมา (ซ่อนปัญหา 5 จุด)
- `answer/answer-key.md` — เฉลย (เปิดหลังลองเองก่อน!)

## Prompt ตัวอย่าง (วางให้ ZCode)

> ในโฟลเดอร์ branches มีรายงานยอดขายเดือน ตุลาคม 2568 ของสาขา 30 แห่ง
> ช่วยรวมเป็น master file ไฟล์เดียว แล้วรายงานด้วยว่า:
> 1. ไฟล์ไหนมีปัญหาอะไร (ข้อมูลว่าง/ซ้ำ/ชนิดข้อมูลผิด/ผิดเดือน) — พร้อมวิธีที่ควรรับมือ
> 2. สรุปยอดขายรวมรายภาค พร้อมกราฟเทียบ
> ห้ามเดาค่าที่ขาด ให้ mark เป็น missing และระบุในรายงาน

## สิ่งที่เดโมดีควรได้

- `master-ตุลาคม-2568.xlsx` — 30 แถว ข้อมูลชนิดถูกต้อง
- รายงานปัญหา **5 จุด** (SC07 ว่าง · SC14 ผิดเดือน · SC22 ข้อความ · SC26 ซ้ำ · SC29 รหัสพิมพ์เล็ก)
- กราฟเทียบยอดขายรายภาค (กลาง/ตะวันออก/เหนือ/อีสาน/ใต้)
