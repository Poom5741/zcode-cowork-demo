# เฉลย Use case 1 — รวมรายงาน 30 สาขา

ไฟล์ที่ถูกต้องควรมี **30 แถวข้อมูล** (รวมเฉพาะเดือน ตุลาคม) และพบปัญหา 5 จุด:

| ไฟล์ | ปัญหา | วิธีรับมือที่ถูกต้อง |
|---|---|---|
| SC07 | ยอดขายออนไลน์**ว่าง** (ลืมกรอก) | ต้อง**แจ้งเตือน** ไม่ใช่นับเป็น 0 — สรุปรวมเงื่อนไข: mark missing |
| SC14 | ยอดออนไลน์ต่ำผิดปกติ เพราะยื่นแบบฟอร์ม**เดือน กันยายน** | ต้อง**แยกออก**ไม่รวมในเดือน ต.ค. + แจ้งให้ส่งใหม่ |
| SC22 | ยอดหน้าร้านเป็น**ข้อความ** "1,234,567 บาท" | parse เป็นตัวเลข แล้ว validate ชนิดข้อมูล |
| SC26 | ข้อมูล**ซ้ำ 2 แถว** | dedupe ก่อนรวม |
| SC29 | รหัสพิมพ์ "sC29" ตัวเล็ก | normalize รหัสเป็นตัวพิมพ์ใหญ่ |

สิ่งที่เดโมดีควรได้: master file เดียว 30 แถว + รายงาน "จุดผิดปกติ 5 จุด" + กราฟเทียบยอดขายรายภาค
