# ZCode Cowork Demo — Mock Data 3 Use case

ชุดข้อมูลจำลองสำหรับเวิร์กช็อป **"ZCode cowork mode — ใช้ AI เป็นลูกน้องสำนักงาน"**
ใช้ได้ทั้งผู้สอน (เดโมบนจอ) และผู้เรียน (ลองทำตามพร้อมกัน) — ข้อมูลทั้งหมดเป็นข้อมูลจำลอง ไม่มีข้อมูลจริงของบริษัทใด

| Use case | โจทย์ | ความยาก | เวลาเดโม |
|---|---|---|---|
| [1 · Excel Consolidation](usecase-1-excel-consolidation/) | รวมรายงานยอดขาย 30 สาขา ที่กรอกมาแบบ "มนุษย์แท้" (มีข้อผิดพลาดซุกซ่อน) | ⭐⭐ | ~3 นาที |
| [2 · Contract Diff](usecase-2-contract-diff/) | เทียบสัญญาจ้าง 2 ร่าง หาว่าคู่สัญญาแก้อะไรหลบตา | ⭐⭐⭐ | ~3 นาที |
| [3 · Folder Search](usecase-3-folder-search/) | หานโยบายค่าคอมมิชชั่นจากโฟลเดอร์ 104 ไฟล์ที่เอกสารขัดแย้งกันเอง | ⭐⭐⭐⭐ | ~5 นาที |

## วิธีใช้ในคลาส

1. แจก repo นี้ (หรือ zip) ให้ผู้เรียน clone
2. เปิด ZCode ที่โฟลเดอร์ use case ที่ต้องการ แล้ววาง prompt จาก README ของ use case นั้น
3. ให้ผู้เรียนเทียบผลกับ `answer/answer-key.md` (เฉลยซ่อนอยู่ — อย่าเปิดก่อนลอง!)

## เกณฑ์ให้คะแนนเดโม (สำหรับผู้สอน)

เอเจนต์ที่ดีไม่ใช่แค่ "ทำได้" แต่ต้อง:
- ✅ จับข้อผิดพลาดแบบมนุษย์ได้ (ไฟล์ว่าง, ข้อมูลซ้ำ, สะกดผิด, ผิดเดือน)
- ✅ **ไม่เดาเอง** เมื่อเอกสารขัดแย้งกัน — ต้องชี้ความขัดแย้งและระบุว่าอันไหนใหม่กว่า
- ✅ แยกคำที่คล้ายกัน (ค่าคอมพนักงาน ≠ คอมมิชชั่นแอฟฟิลิเอต)
- ✅ ส่งมอบเป็น artifact จริง (Excel รวม, ตารางเทียบ, รายงาน)
